# 更新日志

> 维护约定：每次交付新版本都必须在本文件顶部追加一条记录，并把 `pubspec.yaml` 的 `version` 递增（`1.0.N+构建号`，N 每次 +1）。
> 对外显示的版本号统一写成 `v1.0.N`（不带 `+构建号`），日期使用交付当天。

## v1.0.8 · 2026-10-24

### 新增
- 首次启动强制阅读「免责声明与用户须知」：未勾选同意前「同意并继续」不可点击，不同意则退出应用；同意状态保存在本机，之后启动不再出现
- 「我的」→「关于」新增「免责声明与用户须知」入口，可随时回看已同意的条款

### 变更
- 仓库源码地址更新为 `https://github.com/Top-Commenter/HuiShengHuo798`

## v1.0.7 · 2026-10-24

### 修复
- 扫码添加设备后列表不显示：扫码此前只调用 `qr/use` 做了设备识别，并未真正加入「我的设备」。现在识别成功后调用收藏接口完成添加，再返回刷新列表
- 二维码无效 / 设备不存在时给出明确提示（优先显示服务端 `msg`，否则显示 code），不再静默停在扫码页

### 新增
- 设备列表支持拖动排序：每张设备卡右侧新增拖动手柄，顺序保存在本地，重启后保持

### 优化
- 「我的」→「关于」移除历史版本更新内容，仅保留应用名称、版本号、仓库源码、参考项目与免责声明
- 版本号格式统一为 `v1.0.N`，不再使用 `+N` 后缀（原 `v1.0.0+6` 对应 `v1.0.6`）
