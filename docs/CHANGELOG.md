# 更新日志

> 维护约定：每次交付新版本都必须在本文件顶部追加一条记录，并把 `pubspec.yaml` 的 `version` 递增（`1.0.0+N`，N 每次 +1）。
> 版本号与 `pubspec.yaml` 保持一致，日期使用交付当天。

## v1.0.0+3 · 2026-10-24

### 新增
- 首页「每日喝水量」看板：今日饮水总量 + 近 7 天柱状图，仅统计直饮机（排除淋浴器/水表），只计已付款账单
- 新增版本更新文档（本文件），此后每次发版同步追加

### 移除
- 播放音乐模块整体移除（网易云 / QQ 音乐登录、Cookie 粘贴、洗澡自动播放），回归取水工具本质

## v1.0.0+2 · 2026-10-24

### 修复
- 点击「开始」后「停止」按钮长时间置灰：轮询在服务端状态滞后时误判为已停止。改为 15 秒宽限期 + 连续 5 次检测停止才判定结束 + 出水读数增长视为运行中

## v1.0.0+1 · 2026-10-23

- 取水实时费用：从历史账单反推单价（0.3797 元/升），「本次接水 × 单价」每秒刷新

- 「本次接水」在停止状态错误显示累计出水：进入页面时归零基线
