# 更新日志

> 维护约定：每次交付新版本都必须在本文件顶部追加一条记录，并把 `pubspec.yaml` 的 `version` 递增（`1.0.0+N`，N 每次 +1）。
> 版本号与 `pubspec.yaml` 保持一致，日期使用交付当天。

## v1.0.0+6 · 2026-10-24

- 扫码添加设备：「我的设备」标题栏右侧新增扫码按钮，扫描设备二维码即可绑定并刷新列表

### 优化
- 应用安装名改为「饮咩野」（桌面图标名、启动页、登录页、关于页同步）；对外介绍仍为「慧生活798 无广告自定义版」，关于页同时展示两个名称

## v1.0.0+4 · 2026-10-24

### 新增
- 「我的」页新增「关于」入口：显示版本号、可折叠的历史版本更新、仓库源码地址与参考项目地址
